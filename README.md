## Overview
Hands-on implementation of core RAG architecture and agentic capabilities built with Python.

## Core Components
* **Ingestion & Retrieval Pipeline:** Document processing, chunking, embedding generation, and vector store querying.
* **Memory Management:** Conversational context tracking across user sessions.
* **Tool / Function Calling:** Dynamic tool execution routing via LLM function signatures.

## Included Tools & Modules
* `file_reader.py`: Custom file loader for reading and parsing text/document formats.
* `calculator.py`: Mathematical execution tool for deterministic arithmetic.
